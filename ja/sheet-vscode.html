macOS 版 VS Code のキーボードショートカット

これらの VS Code のショートカットはメニューバーに出てこないため、メニューを読み取っても見つかりません。⌘ を長押しすると、Keysi は VS Code のメニューから読み取ったものと並べてこれらを表示します。

ショートカット 25 件 · Keysi がアプリ自身のメニューから読み取る内容に追加 · 無料、Keysi Pro には含まれません。

Keysi で開く Keysi をお持ちでない方は無料でダウンロード

Keysi の 設定 ▸ ショートカット でこのシートを開きます。シートはすでにインストールされています。

このシートを使う

このシートは Keysi にすでに入っています。アプリをインストールして、VS Code で ⌘ を長押しするだけです。

Keysi の 設定 ▸ ショートカット にはVS Codeとして表示されます。

変更するには、下のファイルをダウンロードして ~/Library/Application Support/Keysi/Sheets/ に置きます（設定 ▸ ショートカット ▸「シートフォルダを表示」）。同じ id のシートは内蔵のシートを置き換えるので、変更はそのまま残ります。JSON を触りたくなければ Keysi のエディタを使えます。

アプリ本体にバンドル ID で対応します：com.microsoft.VSCode, com.microsoft.VSCodeInsiders。
