macOS 版 Vim のキーボードショートカット

Vim はターミナルの中で動くため、Keysi が読み取れる macOS のメニューバーがありません。ショートカットはこのシートから表示されます。Vim を前面にしたまま ⌘ を長押しすると表示されます。

ショートカット 73 件 · Keysi がアプリ自身のメニューから読み取る内容に追加 · 無料、Keysi Pro には含まれません。

Keysi で開く Keysi をお持ちでない方は無料でダウンロード

Keysi の 設定 ▸ ショートカット でこのシートを開きます。シートはすでにインストールされています。

このシートを使う

このシートは Keysi にすでに入っています。アプリをインストールして、Vim で ⌘ を長押しするだけです。

Keysi の 設定 ▸ ショートカット にはVimとして表示されます。

変更するには、下のファイルをダウンロードして ~/Library/Application Support/Keysi/Sheets/ に置きます（設定 ▸ ショートカット ▸「シートフォルダを表示」）。同じ id のシートは内蔵のシートを置き換えるので、変更はそのまま残ります。JSON を触りたくなければ Keysi のエディタを使えます。

ターミナルの前面で動いているプログラムに対応します：vim, nvim。Keysi はターミナルの前面ジョブを確認するので、実際にそのプログラムを使っているときにシートが表示されます。

Vim のシートをダウンロード（JSON） Keysi を入手（無料）
