macOS 版 Shell Keys のキーボードショートカット

Shell Keys はターミナルの中で動くため、Keysi が読み取れる macOS のメニューバーがありません。ショートカットはこのシートから表示されます。Shell Keys を前面にしたまま ⌘ を長押しすると表示されます。

ショートカット 7 件 · Keysi がアプリ自身のメニューから読み取る内容に追加 · 無料、Keysi Pro には含まれません。

Keysi で開く Keysi をお持ちでない方は無料でダウンロード

Keysi の 設定 ▸ ショートカット でこのシートを開きます。シートはすでにインストールされています。

基本の行編集

操作キー
行頭⌃A
行末⌃E
前のコマンド⌃P
次のコマンド⌃N
履歴を検索⌃R
行末まで切り取り⌃K
最後の切り取りを貼り付け⌃Y

このシートを使う

このシートは Keysi にすでに入っています。アプリをインストールして、Shell Keys で ⌘ を長押しするだけです。

Keysi の 設定 ▸ ショートカット にはShell Keysとして表示されます。

変更するには、下のファイルをダウンロードして ~/Library/Application Support/Keysi/Sheets/ に置きます（設定 ▸ ショートカット ▸「シートフォルダを表示」）。同じ id のシートは内蔵のシートを置き換えるので、変更はそのまま残ります。JSON を触りたくなければ Keysi のエディタを使えます。

ターミナルの前面で動いているプログラムに対応します：bash, zsh, fish。Keysi はターミナルの前面ジョブを確認するので、実際にそのプログラムを使っているときにシートが表示されます。
