Vim keyboard shortcuts on macOS

Vim runs inside a terminal, so there is no macOS menu bar for Keysi to read, so this sheet is where its shortcuts come from. Hold ⌘ while Vim is in the foreground and they appear.

Use this sheet

It's already in Keysi — install the app and hold ⌘ in Vim. Nothing to download.

Keysi lists it as Vim in Settings ▸ Sheets.

To change it, download the file below and drop it into ~/Library/Application Support/Keysi/Sheets/ (Settings ▸ Sheets ▸ “Reveal Sheets Folder…”). A sheet with the same id replaces the built-in one entirely, so you can fork this and keep your edits. Keysi also has an editor for this, if you'd rather not touch JSON.

Matches the program running in the foreground of a terminal: vim, nvim. Keysi resolves that from the terminal's foreground job, which is why this sheet appears while you are actually in it.
