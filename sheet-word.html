Word keyboard shortcuts on macOS

These are Word shortcuts that never reach its native menu bar, so reading the menus won't find them. Keysi shows them alongside everything it does read from Word's own menus when you hold ⌘.

26 shortcuts · adds to what Keysi reads from the app's own menus · free, and not part of Keysi Pro.

Use this sheet

It's already in Keysi — install the app and hold ⌘ in Word. Nothing to download.

Keysi lists it as Word in Settings ▸ Sheets.

To change it, download the file below and drop it into ~/Library/Application Support/Keysi/Sheets/ (Settings ▸ Sheets ▸ “Reveal Sheets Folder…”). A sheet with the same id replaces the built-in one entirely, so you can fork this and keep your edits. Keysi also has an editor for this, if you'd rather not touch JSON.

Matches the app itself, by bundle identifier: com.microsoft.Word.
