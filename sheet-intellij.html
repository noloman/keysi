IntelliJ IDEA keyboard shortcuts on macOS

These IntelliJ IDEA shortcuts never reach its menu bar, so reading the menus won't find them. Hold ⌘ and Keysi shows them next to everything it reads from IntelliJ IDEA's own menus.

Use this sheet

It's already in Keysi. Install the app and hold ⌘ in IntelliJ IDEA.

Keysi lists it as IntelliJ IDEA in Settings ▸ Shortcuts.

To change it, download the file below and put it in ~/Library/Application Support/Keysi/Sheets/ (Settings ▸ Shortcuts ▸ “Reveal Sheets Folder”). A sheet with the same id replaces the built-in one, so your edits stick. Or use Keysi's editor and skip the JSON.

Matches the app itself, by bundle identifier: com.jetbrains.intellij, com.jetbrains.intellij.ce, com.google.android.studio.
