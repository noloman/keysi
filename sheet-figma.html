Use this sheet

It's already in Keysi. Install the app and hold ⌘ in Figma.

Keysi lists it as Figma (tool shortcuts) in Settings ▸ Shortcuts.

To change it, download the file below and put it in ~/Library/Application Support/Keysi/Sheets/ (Settings ▸ Shortcuts ▸ “Reveal Sheets Folder”). A sheet with the same id replaces the built-in one, so your edits stick. Or use Keysi's editor and skip the JSON.

Matches the app itself, by bundle identifier: com.figma.Desktop.
