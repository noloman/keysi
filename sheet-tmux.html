tmux keyboard shortcuts on macOS

tmux runs inside a terminal, so there's no macOS menu bar for Keysi to read. Its shortcuts come from this sheet instead. Hold ⌘ while tmux is in the foreground and they appear.

37 shortcuts · adds to what Keysi reads from the app's own menus · free, and not part of Keysi Pro.

Use this sheet

It's already in Keysi. Install the app and hold ⌘ in tmux.

Keysi lists it as tmux in Settings ▸ Shortcuts.

To change it, download the file below and put it in ~/Library/Application Support/Keysi/Sheets/ (Settings ▸ Shortcuts ▸ “Reveal Sheets Folder”). A sheet with the same id replaces the built-in one, so your edits stick. Or use Keysi's editor and skip the JSON.

Matches the program in a terminal's foreground: tmux. Keysi checks the terminal's foreground job, so the sheet appears while you're actually in it.
