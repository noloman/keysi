tmux keyboard shortcuts on macOS

tmux runs inside a terminal, so there is no macOS menu bar for Keysi to read — this sheet is where its shortcuts come from. Hold ⌘ while tmux is in the foreground and they appear.

9 shortcuts · adds to what Keysi reads from the app's own menus · free, and not part of Keysi Pro.

Panes

ActionKeys
Split horizontallyCtrl-b %
Split verticallyCtrl-b "
Switch paneCtrl-b <arrow>
Close paneCtrl-b x

Windows

ActionKeys
New windowCtrl-b c
Next / previous windowCtrl-b n / p
Rename windowCtrl-b ,

Sessions

ActionKeys
DetachCtrl-b d
List sessionsCtrl-b s

Use this sheet

It's already in Keysi — install the app and hold ⌘ in tmux. Nothing to download.

Keysi lists it as tmux in Settings ▸ Sheets.

To change it, download the file below and drop it into ~/Library/Application Support/Keysi/Sheets/ (Settings ▸ Sheets ▸ “Reveal Sheets Folder…”). A sheet with the same id replaces the built-in one entirely, so you can fork this and keep your edits. Keysi also has an editor for this, if you'd rather not touch JSON.

Matches the program running in the foreground of a terminal: tmux. Keysi resolves that from the terminal's foreground job, which is why this sheet appears while you are actually in it.
