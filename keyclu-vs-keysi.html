KeyClu vs Keysi

KeyClu is free. So is Keysi. Here's what the $19.99 adds.

KeyClu is a good app, it's actively maintained, and it costs nothing. If all you want is a panel that shows the frontmost app's shortcuts when you ask for one, you should use KeyClu and stop reading here. Genuinely. This page is about the one thing that's actually different.

The difference: KeyClu shows. Keysi teaches.

A shortcut reference, KeyClu included, waits to be asked. You remember that you don't know a shortcut, you invoke the tool, you read it. That works, but it only helps in the moment you already knew you were missing something.

The expensive case is the one you never notice: reaching for the menu forty times a week for a command that has had a shortcut the whole time. You don't look it up, because it doesn't occur to you that there's anything to look up.

Coach mode is aimed at exactly that. Keysi watches for menu commands you pick by hand that already have a keyboard shortcut, and offers one quiet, dismissible reminder, then tracks whether it stuck, so it stops mentioning the ones you've started using. It's throttled by a cooldown so it can't become noise, it's mutable per shortcut or entirely from Settings ▸ Coach, and it keeps a list of what you're still learning so you can work through it deliberately.

And it measures whether it worked. Keysi times how long your own menu trips actually take (the gap between a menu opening and your pick), so it can tell you "your menu trips typically take 2.4s, and you've skipped 412 of them." Not a count multiplied by a number we made up. Two things it counted, with both shown so you can check the arithmetic.

That's the whole pitch, and it's why the cheat sheet itself is free here: we're not charging you for a reference you can already get for nothing. A reference you open is useful. A reference that makes itself unnecessary is what the $19.99 is for.

KeyClu's "Learn" feature is not the same thing

Worth addressing directly, because the names sound similar. KeyClu has a Learn feature, but it hides shortcuts you already know : it narrows the list down to what's still unfamiliar when you open it. That's a useful idea and it works well.

It's also the opposite direction from Coach mode. KeyClu's Learn still only acts when you invoke it, and it's about filtering what's displayed. Coach acts when you didn't invoke anything. It's about the shortcut you weren't going to look up.

The other differences, briefly

  • Click a row to run it. Keysi reads the live menu tree, so clicking a row fires that exact menu action.
  • Conflict warnings. Keysi flags app shortcuts that macOS itself will intercept first, before you press them.
  • Localization. Keysi ships in 9 languages. KeyClu ships 3 built in, with more via community translation.
  • Custom sheets. Keysi ships curated, ready-to-use sheets (Figma, Slack, Vim and tmux) and, since 1.0, a built-in editor for writing your own. Both are free. KeyClu lets you register your own shortcuts manually, optionally paired with a separate CustomShortcuts app. Different mechanisms, both real.

Reasons to pick KeyClu instead

  • It's free, and it's not crippled. There's no upsell, no nag screen, no feature held back. That's rare and it deserves saying.
  • You want to register arbitrary custom shortcuts rather than use curated per-app sheets.
  • You're not on macOS 26. Keysi requires macOS 26 or later.
  • You don't want to be told anything. If a tool proactively surfacing a reminder sounds annoying rather than useful, Coach mode is the entire premium and you shouldn't pay for it. It can be turned off, but then you're buying a lookup panel at a price where a free one exists.

Decide it by running it, not by reading a table

Run Keysi for a week on whatever app you spend the most time in and see how often Coach catches you. If the answer is "rarely," you already know your shortcuts, and either KeyClu or Keysi's own free tier is the right call. The $19.99 only makes sense if the answer is "more often than I'd like."
