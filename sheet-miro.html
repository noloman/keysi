Miro keyboard shortcuts on macOS

Miro runs in your browser, so its shortcuts live in the page, not in any macOS menu bar. Hold ⌘ in Safari, Chrome, Arc, Edge or Brave while Miro is open and Keysi shows them next to the browser's own.

Use this sheet

It's already in Keysi. Install the app and hold ⌘ in Miro.

Keysi lists it as Miro in Settings ▸ Shortcuts.

To change it, download the file below and put it in ~/Library/Application Support/Keysi/Sheets/ (Settings ▸ Shortcuts ▸ “Reveal Sheets Folder”). A sheet with the same id replaces the built-in one, so your edits stick. Or use Keysi's editor and skip the JSON.

In a browser, matches the page that is open: miro.com/app.
