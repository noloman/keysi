What actually happened to CheatSheet

The common assumption is that Apple removed or locked down the accessibility API CheatSheet relied on. That isn't what happened. AXUIElementCreateApplication and the menu-bar AX attributes are still public, still documented, and still return correct data on current macOS, verified directly against TextEdit, Safari, Finder, Xcode, VS Code, Slack, and Figma, the last three being Electron apps.

CheatSheet stopped working because its maintainer moved on, not because the technique stopped being possible. That distinction is the whole reason Keysi exists, and it's also the honest answer to the obvious follow-up question below.

What you get back, and what's new

If you used CheatSheet, the core is the same and you'll be at home immediately: hold a modifier, the frontmost app's shortcuts appear grouped by menu, release and they're gone. Three things are different:

  • Every row is clickable. Keysi reads the live menu tree, so clicking a row fires that exact menu action. It isn't a picture of the menu. It is the menu.
  • It warns you when a shortcut is a lie. Keysi reads macOS's own system shortcuts and flags any app shortcut the system will intercept first, so you're not left wondering why nothing happened.
  • It teaches, not just displays. Coach mode notices when you pick a command from the menu with the mouse that already has a keyboard shortcut, and tells you once, then tracks whether it stuck, so it stops mentioning the ones you've learned. CheatSheet never did this, and neither does anything else in this category.

Differences worth knowing before you switch

  • ⌘ is the only hold modifier. CheatSheet let you choose. Keysi currently hardcodes ⌘. If you trained yourself on a different key, that's a real adjustment.
  • You can't type to search while holding ⌘. A global event monitor can observe keystrokes but not consume them, so anything typed would still reach the app underneath. Keysi will not install the kind of input tap that could change that. There's a separate global hotkey (⇧⌘K by default) that opens the same content as a real panel, where search, arrow keys, and Escape all work.
  • Part of Keysi is paid. The cheat sheet, the thing CheatSheet actually did, is free, with no time limit, no account and no card. The $19.99 buys Keysi Pro, which is coaching rather than reference: it notices when you pick a menu command with the mouse that has a shortcut, and drills the ones you keep missing. If you only want CheatSheet back, you never have to pay.
  • macOS 14 or later. If you're on an older macOS, Keysi won't run.

"Won't this just die the same way?"

Fair question, and the reason to ask it is exactly right. The honest answer has two parts. First, the underlying API is public and unchanged. CheatSheet died of maintainer exit, not of API removal, so the failure mode people remember isn't the one that was actually at play. Second, no promise about the future is worth anything on a marketing page. What's checkable is the changelog: that's the ongoing evidence, and it's the thing to judge this on.

Not affiliated with Media Atelier

Keysi shares no code with CheatSheet. It's an independent app built on the same public accessibility API, by someone who used CheatSheet daily and wanted it back. The name, the icon, and the implementation are entirely separate.
