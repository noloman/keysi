Mac keyboard shortcuts

macOS keyboard shortcuts: where to find and learn them

macOS keyboard shortcuts come from two places: the operating system and the app you are using. Knowing which one you need makes it much easier to find a command, fix a conflict, or turn a mouse habit into a shortcut.

System shortcuts and app shortcuts are different

System shortcuts belong to macOS. They cover actions such as Mission Control, Spotlight, screenshots, input sources and accessibility features. You can review and change them in System Settings ▸ Keyboard ▸ Keyboard Shortcuts.

App shortcuts belong to a particular app. Xcode, Finder, Safari, Mail and every other Mac app can add commands to their own menus. Their shortcuts appear beside those commands and can change with the app's version, selection and current window. macOS does not provide one built-in screen containing every app's shortcuts.

How to see the shortcuts in the app you are using

  1. Open the app's menu bar and look beside its commands.
  2. Use the Help menu's search field when the app supports menu search.
  3. Hold ⌘ with Keysi to see the frontmost app's live menu shortcuts together, including commands inside submenus.

How to create a custom shortcut

macOS can assign a shortcut to an app menu command that does not already have one. Open System Settings ▸ Keyboard ▸ Keyboard Shortcuts ▸ App Shortcuts, choose the app, enter the command's exact menu title, and choose a key combination. The title must match the menu item, including punctuation when the app uses it.

When a keyboard shortcut does nothing

First check whether macOS or another utility already owns the combination. A shortcut can remain printed in an app's menu even when the system handles the keystroke before the app receives it. Keysi can flag app shortcuts that macOS will intercept, so you can spot that conflict while reading the list.

How to make shortcuts stick

A shortcut list is useful when you need an answer. Learning happens when you use the command you already reach for and press its keys the next time. Common questions

Where are macOS keyboard shortcuts listed?

System-wide shortcuts are in System Settings under Keyboard, Keyboard Shortcuts. App-specific shortcuts live in each app's menus, so there is no single built-in list for every Mac app.

How do I see the keyboard shortcuts for the Mac app I am using?

Look next to commands in the app's menu bar, search the app's menus from Help when it supports that feature, or hold Command with Keysi to see the frontmost app's live menu shortcuts together.

Can I create a custom keyboard shortcut on macOS?

Yes. Use System Settings ▸ Keyboard ▸ Keyboard Shortcuts ▸ App Shortcuts and enter the exact title of a menu command exposed by the app.

Why does a Mac keyboard shortcut sometimes do nothing?

The combination may already be assigned to macOS or another application, or the command may be unavailable for the current selection. The menu can still show the shortcut even when another system shortcut receives the keystroke first.
