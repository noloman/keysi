Tastaturkurzbefehle für GitHub unter macOS

GitHub läuft im Browser, seine Kurzbefehle stecken also in der Seite, nicht in einer macOS-Menüleiste. Halte ⌘ in Safari, Chrome, Arc, Edge oder Brave, während GitHub offen ist, und Keysi zeigt sie neben denen des Browsers.

Diesen Spickzettel verwenden

Er ist schon in Keysi enthalten. Installiere die App und halte ⌘ in GitHub gedrückt.

Keysi führt ihn unter Einstellungen ▸ Tastaturkurzbefehle als GitHub.

Um ihn zu ändern, lade die Datei unten herunter und lege sie in ~/Library/Application Support/Keysi/Sheets/ ab (Einstellungen ▸ Tastaturkurzbefehle ▸ „Spickzettel-Ordner anzeigen“). Ein Spickzettel mit derselben id ersetzt den mitgelieferten, deine Änderungen bleiben also erhalten. Oder nimm Keysis Editor und lass das JSON beiseite.

Im Browser passend zur geöffneten Seite: github.com.
