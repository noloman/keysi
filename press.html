Description (100 words)

Keysi is a macOS menu-bar utility that reveals — and runs — the keyboard shortcuts of whatever app is frontmost. Hold ⌘ for a glance, or press a global hotkey for a searchable panel. It reads the app's real menu structure live via the Accessibility API, so every shortcut is accurate to that exact app in that exact state, dimmed when unavailable, and flagged when macOS will intercept it first. Custom JSON cheat sheets cover apps with no real menu bar at all, like Vim and tmux. Keysi is a modern, independent recreation of CheatSheet by Media Atelier, discontinued on macOS Sonoma. €14.99, one-time purchase, 14-day free trial.

The one line every writer should have

Not affiliated with Media Atelier. Keysi shares no code with CheatSheet — it's a new app built on the same public accessibility API.
