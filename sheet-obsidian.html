These are Obsidian shortcuts that never reach its native menu bar, so reading the menus won't find them. Keysi shows them alongside everything it does read from Obsidian's own menus when you hold ⌘.

Use this sheet

It's already in Keysi — install the app and hold ⌘ in Obsidian. Nothing to download.

Keysi lists it as Obsidian in Settings ▸ Sheets.

To change it, download the file below and drop it into ~/Library/Application Support/Keysi/Sheets/ (Settings ▸ Sheets ▸ “Reveal Sheets Folder…”). A sheet with the same id replaces the built-in one entirely, so you can fork this and keep your edits. Keysi also has an editor for this, if you'd rather not touch JSON.

Matches the app itself, by bundle identifier: md.obsidian.
