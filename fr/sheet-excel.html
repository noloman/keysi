Raccourcis clavier de Excel sur macOS

Ces raccourcis de Excel n’apparaissent jamais dans sa barre des menus : lire les menus ne permet donc pas de les trouver. Maintenez ⌘ et Keysi les affiche à côté de tout ce qu’il lit dans les menus de Excel.

29 raccourcis · s’ajoutent à ce que Keysi lit dans les menus de l’app · gratuit, et hors de Keysi Pro.

Affiche cette fiche dans Réglages ▸ Raccourcis de Keysi, où elle est déjà installée.

Utiliser cette fiche

Elle est déjà dans Keysi. Installez l’app et maintenez ⌘ dans Excel.

Keysi l’affiche sous le nom Excel dans Réglages ▸ Raccourcis.

Pour la modifier, téléchargez le fichier ci-dessous et placez-le dans ~/Library/Application Support/Keysi/Sheets/ (Réglages ▸ Raccourcis ▸ « Afficher le dossier des fiches »). Une fiche avec le même id remplace celle intégrée, donc vos modifications restent. Ou utilisez l’éditeur de Keysi et oubliez le JSON.

Associée à l’app elle-même, par son identifiant de bundle : com.microsoft.Excel.
