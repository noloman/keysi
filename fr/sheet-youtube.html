Raccourcis clavier de YouTube sur macOS

YouTube tourne dans votre navigateur : ses raccourcis vivent dans la page, pas dans une barre de menus macOS. Maintenez ⌘ dans Safari, Chrome, Arc, Edge ou Brave avec YouTube ouvert, et Keysi les affiche à côté de ceux du navigateur.

23 raccourcis · s’ajoutent à ce que Keysi lit dans les menus de l’app · gratuit, et hors de Keysi Pro.

Utiliser cette fiche

Elle est déjà dans Keysi. Installez l’app et maintenez ⌘ dans YouTube.

Keysi l’affiche sous le nom YouTube dans Réglages ▸ Raccourcis.

Pour la modifier, téléchargez le fichier ci-dessous et placez-le dans ~/Library/Application Support/Keysi/Sheets/ (Réglages ▸ Raccourcis ▸ « Afficher le dossier des fiches »). Une fiche avec le même id remplace celle intégrée, donc vos modifications restent. Ou utilisez l’éditeur de Keysi et oubliez le JSON.

Dans un navigateur, correspond à la page ouverte : youtube.com.
