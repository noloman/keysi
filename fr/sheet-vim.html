Raccourcis clavier de Vim sur macOS

Vim s’exécute dans un terminal : il n’y a donc pas de barre des menus macOS que Keysi puisse lire. Ses raccourcis viennent de cette fiche. Maintenez ⌘ pendant que Vim est au premier plan et ils s’affichent.

73 raccourcis · s’ajoutent à ce que Keysi lit dans les menus de l’app · gratuit, et hors de Keysi Pro.

Affiche cette fiche dans Réglages ▸ Raccourcis de Keysi, où elle est déjà installée.

Utiliser cette fiche

Elle est déjà dans Keysi. Installez l’app et maintenez ⌘ dans Vim.

Keysi l’affiche sous le nom Vim dans Réglages ▸ Raccourcis.

Pour la modifier, téléchargez le fichier ci-dessous et placez-le dans ~/Library/Application Support/Keysi/Sheets/ (Réglages ▸ Raccourcis ▸ « Afficher le dossier des fiches »). Une fiche avec le même id remplace celle intégrée, donc vos modifications restent. Ou utilisez l’éditeur de Keysi et oubliez le JSON.

Associée au programme au premier plan d’un terminal : vim, nvim. Keysi regarde la tâche au premier plan du terminal, donc la fiche apparaît quand vous êtes réellement dedans.
