What's new

This mirrors CHANGELOG.md in the repository. Kept up to date with every release.

1.0.0 Initial release

  • Hold ⌘ to reveal the frontmost app's keyboard shortcuts, grouped by menu, with breadcrumbs for submenu-nested items
  • Real keycap rendering (⌘⇧S) instead of text notation
  • Click any shortcut row to run it
  • Global hotkey (default ⇧⌘K) for a searchable, interactive panel, with live modifier filtering, ranked search, and full keyboard navigation
  • System-shortcut conflict warnings
  • Free forever: the overlay, click-to-run, search, custom cheat sheets, conflict warnings, favorites and hiding. Not a trial — this part never stops working
  • Keysi Pro ($9.99, one-time) adds the coaching: Shortcut Coach, Practice Mode, your measured progress, and a weekly summary. Every install includes 14 days of it, and when that ends Keysi drops to the free tier rather than stopping
  • Shortcut Coach — notices when you pick a menu command with the mouse that already has a keyboard shortcut, and offers one quiet, dismissible reminder. Mute any single shortcut, or the whole feature, from Settings ▸ Coach
  • Progress you can check: Keysi times how long your own menu trips take, so "you've skipped 412 of them" is arithmetic on two measured numbers rather than a guess. No invented "hours saved"
  • Practice Mode, drilling the shortcuts you keep reaching for the mouse for, and an optional weekly summary of what stuck
  • Configurable hold modifier — ⌘, ⌥, ⌃ or ⇧
  • Custom cheat sheets, with built-in sheets for Figma, Slack, Vim, and tmux, plus an editor for writing your own — no hand-editing JSON
  • Localized into 9 languages: English, Spanish, French, German, Italian, Portuguese (Brazil), Japanese, Korean, and Simplified Chinese
  • Configurable hold delay, rebindable hotkey, optional menu bar icon, launch at login
  • Secure-input awareness
  • Opt-in crash diagnostics — off by default, generated on-device via MetricKit, never transmitted automatically even when enabled
  • Signed updates via Sparkle
  • Opt-in usage analytics (off by default) — app launches, Settings tab opens, the overlay showing, which shortcuts get triggered, and licensing/upgrade events; never a license key or payment detail. See the privacy page for the full disclosure
  • Licensing via Gumroad — 14 days of Keysi Pro, then free forever
