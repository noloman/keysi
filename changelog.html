1.0.0 Initial release

  • Hold ⌘ to reveal the frontmost app's keyboard shortcuts, grouped by menu, with breadcrumbs for submenu-nested items
  • Real keycap rendering (⌘⇧S) instead of text notation
  • Click any shortcut row to run it
  • Global hotkey (default ⇧⌘K) for a searchable, interactive panel
  • System-shortcut conflict warnings
  • Custom JSON cheat sheets, with built-in sheets for Vim, tmux, Figma, and Slack
  • Configurable hold delay, rebindable hotkey, optional menu bar icon, launch at login
  • Secure-input awareness
  • Signed updates via Sparkle
  • Licensing via Lemon Squeezy — 14-day free trial, €14.99 one-time purchase
  • Opt-in, fully local crash diagnostics (off by default) — generated on-device by MetricKit, never transmitted automatically
  • Opt-in usage analytics (off by default) — see the privacy page for exactly what's collected
