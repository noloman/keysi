VS Code keyboard shortcuts on macOS

These VS Code shortcuts never reach its menu bar, so reading the menus won't find them. Hold ⌘ and Keysi shows them next to everything it reads from VS Code's own menus.

Use this sheet

It's already in Keysi. Install the app and hold ⌘ in VS Code.

Keysi lists it as VS Code in Settings ▸ Shortcuts.

To change it, download the file below and put it in ~/Library/Application Support/Keysi/Sheets/ (Settings ▸ Shortcuts ▸ “Reveal Sheets Folder”). A sheet with the same id replaces the built-in one, so your edits stick. Or use Keysi's editor and skip the JSON.

Matches the app itself, by bundle identifier: com.microsoft.VSCode, com.microsoft.VSCodeInsiders.
